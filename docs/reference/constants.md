# `wp-config.php` Constants

| Constant                           | Description                                                                                          |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `PLUGIN_SKELETON_D_AUTOLOAD`       | Set to `false` to skip loading the bundled `vendor-prefixed/autoload.php` and `vendor/autoload.php`. |
| `PLUGIN_SKELETON_D_ENCRYPTION_KEY` | Used to encrypt/decrypt data before storing in the database.                                         |
